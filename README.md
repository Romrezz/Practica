\# Памятка пользователя Git

\## Основные команды:

\*\*Узнать в какой директории вы сейчас находитесь:\*\*

```

pwd

```

\*\*Перейти в другую директорию:\*\*

```

cd # \*в качестве аргумента указываем папку в которую хотим перейти\*

```	

\*\*Отобразить содержимое директории:\*\*

```

ls

```

\*\*Создание файлов и директорий:\*\*

```

touch ## \*создали файл\*

mkdir ## \*создали директорию\*

```

\*\*Копирование файлов и папок:\*\*

```

cp ## \*в качестве параметров указываем: \*\*что копируем?\*\* и \*\*куда копируем?\*\* \* 

```

\*\*Перемещение файлов и папок:\*\*

```

mv ## \*синтаксис команды\* mv \*аналогичен синтаксису команды\* cp

```

\*\*Прочитать файл:\*\*

```

cat # \*в качестве аргумента указываем нужный файл\*

```

\*\*Удаление файлов и папок:\*\*

```

rm # \*удалить файл\*

rmdir # \*удалить папку\*

rm -r # \*удалить папку со всем её содержимым\*

```
